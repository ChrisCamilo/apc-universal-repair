**Windows:** installed apps update themselves to this version, and the server at home follows them. To install from scratch, download `APC-Universal-Repair-Setup-0.2.1.exe`, or the portable exe to run without installing.

### What's new
- **The window fits small screens:** on a 1366×768 or 1360×768 notebook the window opens above the taskbar, at what the screen holds, and can be made as small as 1280×640. The page itself never scrolls; only the Inventory's table does.
- **The APC logo on the taskbar,** in every way the app runs, instead of Electron's icon, from a new icon file with every size Windows asks for.
- **A livelier day mode:** each style is tinted in its own hue by day, with no white panels: sand for Anos 80, steel blue for GT4, warm grey-red for BMW 90 and sage for Fiat 90. Selections carry more of the style's color, and every text and status color keeps WCAG AA contrast.
- **Migrations on a new computer:** an empty database now migrates in one go.

### Novidades
- **A janela cabe em telas pequenas:** num notebook de 1366×768 ou 1360×768 a janela abre acima da barra de tarefas, no tamanho que a tela comporta, e pode diminuir até 1280×640. A página em si nunca rola; só a tabela do Estoque.
- **O logo do APC na barra de tarefas,** em todo jeito de rodar o app, no lugar do ícone do Electron, a partir de um arquivo de ícone novo com todos os tamanhos que o Windows pede.
- **Um modo claro com mais vida:** de dia cada estilo é tingido no seu próprio tom, sem painéis brancos: areia no Anos 80, azul-aço no GT4, cinza-avermelhado no BMW 90 e sálvia no Fiat 90. As seleções levam mais da cor do estilo, e todo texto e cor de status mantém o contraste AA do WCAG.
- **Migrações num computador novo:** um banco vazio agora migra de uma vez.
