**Windows:** download `APC-Universal-Repair-Setup-0.2.0.exe` to install, or the portable exe to run without installing. On a computer with v0.1.0, run the new installer over it, without uninstalling: the data is kept. From this version on, the installed app updates itself.

### What's new
- **The app updates itself** from these releases. It checks when it opens and every 6 hours, downloads in the background and installs when it closes, or right away with *Reiniciar agora*.
- **The server at home follows the app:** when the API on this computer is at another version, the app brings it to its own release as it opens, showing *Atualizando o servidor*, and goes back if that fails. A server on another computer only gets a warning.
- **Notifications and toasts:** success, error, info and warning toasts in their own colors, fading in and out. A bell beside the user menu keeps the latest notifications, and its menu sets how long a toast stays (5 s by default).
- **Low stock warnings** for parts at or below their minimum, once while they stay low.
- **Windows notifications** of errors and warnings while the window is in the background. Clicking one opens the bell.
- **Inventory:** the tutorial runs only on a user's first login, the toolbar buttons stay at the right edge, and the Dashboard fits the window, with only the list scrolling.

**Windows:** baixe o `APC-Universal-Repair-Setup-0.2.0.exe` para instalar, ou o exe portátil para rodar sem instalar. Num computador com a v0.1.0, rode o instalador novo por cima, sem desinstalar: os dados são mantidos. A partir desta versão, o app instalado se atualiza sozinho.

### Novidades
- **O app se atualiza sozinho** por estas releases. Ele procura uma versão nova ao abrir e a cada 6 horas, baixa em segundo plano e instala ao fechar, ou na hora com *Reiniciar agora*.
- **O servidor em casa acompanha o app:** quando a API deste computador está em outra versão, o app a leva para a própria release ao abrir, mostrando *Atualizando o servidor*, e volta atrás se não der certo. Um servidor em outro computador só gera um aviso.
- **Notificações e toasts:** toasts de sucesso, erro, informação e aviso, cada um na sua cor, aparecendo e sumindo aos poucos. Um sino ao lado do menu do usuário guarda as últimas notificações, e o menu dele ajusta quanto tempo o toast fica na tela (5 s por padrão).
- **Avisos de estoque baixo** para peças no mínimo ou abaixo dele, uma vez enquanto continuarem baixas.
- **Notificações do Windows** de erros e avisos enquanto a janela está em segundo plano. Clicar numa delas abre o sino.
- **Estoque:** o tutorial roda só no primeiro login de cada usuário, os botões da barra ficam no canto direito, e o Dashboard cabe na janela, com só a lista rolando.
