**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.8.5.exe`, or the portable exe to run without installing.

**Android:** the installed app says when this version is out and opens its APK, `apc-universal-repair-0.8.5.apk`. To install from scratch, open that file on the phone.

### What's new
- **Only the vehicles with parts in the Catalog** (#491): the "Só com peças" switch, under the brand search (above the brands on a phone), shows only the models some part in stock fits, and the brands with one, so the Catalog isn't filled with every vehicle of the lists. Each device remembers it. Adding a brand or a model turns it off, so the new one shows.
- **The chosen row stands out in the Catalog** (#490): a generation, or any row of the model tree, takes the accent when clicked, and the rows above it a softer one, so a generation chosen on its own stands out more than when a version inside it is chosen.

### Fixes
- **The Catalog tree no longer jumps** (#490): pointing at a row, which shows its buttons, no longer makes it grow and the rows under it move.

**Windows:** os apps instalados se atualizam sozinhos para esta versão. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.8.5.exe`, ou o exe portátil para rodar sem instalar.

**Android:** o app instalado avisa quando esta versão sai e abre o APK dela, o `apc-universal-repair-0.8.5.apk`. Para instalar do zero, abra esse arquivo no celular.

### Novidades
- **Só os veículos com peças no Catálogo** (#491): a chave "Só com peças", embaixo da busca de marca (acima das marcas no celular), mostra só os modelos em que alguma peça do estoque serve, e as marcas que têm um, para o Catálogo não ficar cheio de todos os veículos das listas. Cada aparelho lembra a escolha. Adicionar uma marca ou um modelo a desliga, para o novo aparecer.
- **A linha escolhida se destaca no Catálogo** (#490): uma geração, ou qualquer linha da árvore de modelos, fica na cor de destaque ao ser clicada, e as linhas acima dela num tom mais suave, então uma geração escolhida sozinha se destaca mais do que quando uma versão dentro dela é escolhida.

### Correções
- **A árvore do Catálogo não treme mais** (#490): passar o mouse numa linha, que mostra os botões dela, não a faz mais crescer e mexer as linhas de baixo.
