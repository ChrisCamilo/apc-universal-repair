**Windows:** installed apps update themselves to this version. The server now comes inside the app, so a computer that ran it from a clone moves off it once, as below. To install from scratch, download `APC-Universal-Repair-Setup-0.4.0.exe`, or the portable exe to run without installing.

### What's new
- **The server comes with the app:** the installer brings the server, and the app runs it on port 3333 for the phone. There is no clone, Node.js or pnpm to install, and no task or shortcut to set up.
  - Its data is in `%APPDATA%\APC Universal Repair\data`, the SQLite file and the photos, and its log in `logs\api.log`.
  - An update of the app updates the server and its database together.
  - The first time it starts, Windows asks whether APC may use the network: allow it on private networks only.
- **In the tray:** closing the window keeps the app by the clock, with the server on for the phone. The tray's menu opens the app, shows the phone's address (a click copies it), opens the server's settings, turns *Iniciar com o Windows* on and off, and quits with *Sair*, which turns the server off.
- **Starting with Windows:** the installer asks whether the app starts hidden in the tray when you sign in, with the server on (yes by default).
- **The database in the app:** *Servidor e banco de dados*, in the user menu and the tray's menu, shows the database in use, the photos' folder, the port and the phone's address.
  - It moves the server to PostgreSQL, checking the address connects and creating the tables first, or back to SQLite.
  - PostgreSQL's address holds a password, so it is kept sealed by Windows (DPAPI), never in plain text.
  - With PostgreSQL chosen at install, the app asks for its address on its first start.
- **Importing an old server:** *Importar dados de outro servidor*, in the same dialog, brings an old server's data and photos into a fresh install, from its PostgreSQL address or SQLite file. An old database of an earlier version is updated first, once you agree.
- **The installer's notes** no longer get cut at their quoted names.

### Moving off a clone
A computer that ran the server from a clone (up to v0.3.0) moves to the server inside the app once. The [home server guide](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#8-moving-off-a-clone) has the details:
1. **Stop the clone's server for good:** in the clone's folder, run `powershell -ExecutionPolicy Bypass -File apps\api\scripts\uninstall-task.ps1`, or delete the *APC Universal Repair API* task in the Task Scheduler. Delete the *Ligar servidor APC* shortcut too.
2. **Open the updated app,** without signing up. If `config.json` in `%APPDATA%\APC Universal Repair` sets `apiDir` or `apiUrl` for the clone, remove them. With PostgreSQL chosen at install, the app asks for its address.
3. **Import the data:** in *Servidor e banco de dados*, *Importar dados de outro servidor*, pick the clone's `apps\api\data\apc.db`, or the address in its `apps\api\.env`, and its `apps\api\uploads\photos`. Then log in with an old account.
4. **Delete the clone** once you're sure.

**Windows:** os apps instalados se atualizam sozinhos para esta versão. O servidor agora vem dentro do app, então um computador que o rodava de um clone sai dele uma vez, como abaixo. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.4.0.exe`, ou o exe portátil para rodar sem instalar.

### Novidades
- **O servidor vem com o app:** o instalador traz o servidor, e o app o roda na porta 3333 para o celular. Não há clone, Node.js nem pnpm para instalar, nem tarefa ou atalho para configurar.
  - Os dados ficam em `%APPDATA%\APC Universal Repair\data`, o arquivo SQLite e as fotos, e o log em `logs\api.log`.
  - Uma atualização do app atualiza o servidor e o banco juntos.
  - Na primeira vez que ele liga, o Windows pergunta se o APC pode usar a rede: permita só em redes privadas.
- **Na bandeja:** fechar a janela deixa o app perto do relógio, com o servidor ligado para o celular. O menu da bandeja abre o app, mostra o endereço do celular (um clique copia), abre as configurações do servidor, liga e desliga o *Iniciar com o Windows* e sai com *Sair*, que desliga o servidor.
- **Iniciar com o Windows:** o instalador pergunta se o app liga escondido na bandeja quando você entra, com o servidor ligado (sim por padrão).
- **O banco no app:** o *Servidor e banco de dados*, no menu do usuário e no menu da bandeja, mostra o banco em uso, a pasta das fotos, a porta e o endereço do celular.
  - Ele passa o servidor para o PostgreSQL, conferindo antes se o endereço conecta e criando as tabelas, ou de volta para o SQLite.
  - O endereço do PostgreSQL tem uma senha, então ele fica lacrado pelo Windows (DPAPI), nunca em texto puro.
  - Com o PostgreSQL escolhido na instalação, o app pede o endereço dele na primeira vez que abre.
- **Importar um servidor antigo:** o *Importar dados de outro servidor*, no mesmo diálogo, traz os dados e as fotos de um servidor antigo para uma instalação nova, do endereço PostgreSQL ou do arquivo SQLite dele. Um banco antigo de uma versão anterior é atualizado antes, se você concordar.
- **As notas do instalador** não são mais cortadas nos nomes entre aspas.

### Sair de um clone
Um computador que rodava o servidor de um clone (até a v0.3.0) passa uma vez para o servidor dentro do app. O [guia do servidor em casa](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#8-sair-de-um-clone) tem os detalhes:
1. **Desligue de vez o servidor do clone:** na pasta do clone, rode `powershell -ExecutionPolicy Bypass -File apps\api\scripts\uninstall-task.ps1`, ou apague a tarefa *APC Universal Repair API* no Agendador de Tarefas. Apague também o atalho *Ligar servidor APC*.
2. **Abra o app atualizado,** sem criar conta. Se o `config.json` em `%APPDATA%\APC Universal Repair` define `apiDir` ou `apiUrl` para o clone, tire-os. Com o PostgreSQL escolhido na instalação, o app pede o endereço dele.
3. **Importe os dados:** no *Servidor e banco de dados*, *Importar dados de outro servidor*, escolha o `apps\api\data\apc.db` do clone, ou o endereço do `apps\api\.env` dele, e o `apps\api\uploads\photos` dele. Depois entre com uma conta antiga.
4. **Apague o clone** quando tiver certeza.
