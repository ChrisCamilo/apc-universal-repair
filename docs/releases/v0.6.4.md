**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.6.4.exe`, or the portable exe to run without installing.

### What's new
- **The server stays on this computer** (#289):
  - out of the box, the server the app runs answers only this computer. Nothing on the network reaches it, and Windows no longer asks about its firewall on the first start;
  - *Servidor e banco de dados* has a new *Acesso pelo celular* switch. It puts the server on the network for the phone, and shows the address the phone reaches it at, until it is turned off again;
  - while it is off, the tray says *Servidor ligado só neste computador*.
- **A warning about public networks** (#215): while the phone's access is on, the dialog warns when the Wi-Fi is set to *Public*, or a firewall rule lets APC in on public networks. It only reads these settings and never changes them. The [home server guide](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#3-allow-it-through-the-firewall) says how to fix them, how to keep PostgreSQL on this computer only, and that on SQLite the Windows account's password or PIN guards the data.
- **Importing on the first start** (#243): while the database is empty, the app offers, over the login and the sign-up, to import an old server before anyone signs up. *Importar de um servidor antigo* opens the import, and *Começar do zero* stops the offer.

### Fixes
- **The import offer over the Dashboard** (#295): the offer no longer shows after a quick sign-up, when the check of the empty database answered late.

**Windows:** os apps instalados se atualizam sozinhos para esta versão. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.6.4.exe`, ou o exe portátil para rodar sem instalar.

### Novidades
- **O servidor fica neste computador** (#289):
  - de fábrica, o servidor que o app roda responde só a este computador. Nada na rede chega a ele, e o Windows não pergunta mais do firewall na primeira abertura;
  - o *Servidor e banco de dados* ganhou o botão *Acesso pelo celular*. Ele põe o servidor na rede para o celular e mostra o endereço em que o celular chega a ele, até ser desligado de novo;
  - enquanto ele está desligado, a bandeja diz *Servidor ligado só neste computador*.
- **Aviso de rede pública** (#215): com o acesso pelo celular ligado, o diálogo avisa quando o Wi-Fi está como *Pública*, ou uma regra do firewall libera o APC em redes públicas. Ele só lê essas configurações e nunca as muda. O [guia do servidor em casa](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#3-liberar-no-firewall) diz como corrigi-las, como deixar o PostgreSQL só neste computador e que, no SQLite, a senha ou o PIN da conta do Windows é o que protege os dados.
- **Importar na primeira abertura** (#243): enquanto o banco está vazio, o app oferece, sobre o login e o cadastro, importar um servidor antigo antes de alguém criar conta. O *Importar de um servidor antigo* abre a importação, e o *Começar do zero* para de oferecer.

### Correções
- **A oferta de importar sobre o Dashboard** (#295): a oferta não aparece mais depois de um cadastro rápido, quando a checagem do banco vazio respondia atrasada.
