**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.5.0.exe`, or the portable exe to run without installing.

### What's new
- **All rights reserved:** APC Universal Repair now has a license, in `LICENSE`. The code is public to be read and evaluated only: copying, using, changing or distributing it, in whole or in part, needs the author's written permission.
- **Third-party notices:** the app ships `LICENSE.txt` and `THIRD_PARTY_NOTICES.md` in its installation folder, beside Electron's and Chromium's own notices. They have the license of every open-source package it carries, as those licenses ask.
- **Every package audited:** each package the project installs had its license checked, and none asks to open the project's code. The audit is in [docs/licenses.md](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/licenses.md), and CI refuses a new dependency with a license outside the allowed ones.

### Novidades
- **Todos os direitos reservados:** o APC Universal Repair agora tem uma licença, no `LICENSE`. O código é público só para ser lido e avaliado: copiar, usar, alterar ou distribuir, no todo ou em parte, pede a autorização por escrito do autor.
- **Avisos de terceiros:** o app leva o `LICENSE.txt` e o `THIRD_PARTY_NOTICES.md` na pasta de instalação, ao lado dos avisos do Electron e do Chromium. Eles trazem a licença de cada pacote de código aberto que ele usa, como essas licenças pedem.
- **Todos os pacotes auditados:** cada pacote que o projeto instala teve a licença conferida, e nenhum pede para abrir o código do projeto. A auditoria está no [docs/licenses.md](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/licenses.md), e o CI recusa uma dependência nova com uma licença fora das permitidas.
