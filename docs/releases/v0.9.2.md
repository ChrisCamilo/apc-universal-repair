**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.9.2.exe`, or the portable exe to run without installing.

**Android:** the installed app says when this version is out and opens its APK, `apc-universal-repair-0.9.2.apk`. To install from scratch, open that file on the phone.

### What's new
- **The apps in Portuguese or English** (#543 to #546, #550): *Idioma*, in the user menu, switches the computer's and the phone's screens between Portuguese and English at once, the phone's notifications included. Each device keeps its own choice. The apps start in Portuguese, as before.
- **What the server refuses, in the language chosen** (#547): a message from the server, such as a part code already in use or an item another device deleted, shows in the app's language. A device authorized without a name is shown by its code, as "Dispositivo" or "Device".
- **The desktop app's own windows in the language chosen** (#548): the tray's menu, its notifications, the screens while the server starts or an update goes in, and the messages of *Servidor e banco de dados* follow the language. *Sobre esta versão* shows these notes in English when English is chosen.
- **The installer in Portuguese or English** (#549): a new install asks its language first, Portuguese chosen, and its pages and the uninstaller's follow it. The app then opens in that language the first time. Updating from 0.9.1 asks nothing and stays in Portuguese.

**Windows:** os apps instalados se atualizam sozinhos para esta versão. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.9.2.exe`, ou o exe portátil para rodar sem instalar.

**Android:** o app instalado avisa quando esta versão sai e abre o APK dela, o `apc-universal-repair-0.9.2.apk`. Para instalar do zero, abra esse arquivo no celular.

### Novidades
- **Os apps em português ou inglês** (#543 a #546, #550): o *Idioma*, no menu do usuário, troca na hora as telas do computador e do celular entre português e inglês, incluindo as notificações do celular. Cada aparelho guarda a sua escolha. Os apps começam em português, como antes.
- **O que o servidor recusa, no idioma escolhido** (#547): uma mensagem do servidor, como um código de peça já usado ou um item que outro aparelho excluiu, aparece no idioma do app. Um aparelho autorizado sem nome aparece pelo código dele, como "Dispositivo" ou "Device".
- **As janelas do próprio app desktop no idioma escolhido** (#548): o menu da bandeja, as notificações dele, as telas enquanto o servidor liga ou uma atualização entra, e as mensagens do *Servidor e banco de dados* seguem o idioma. O *Sobre esta versão* mostra estas notas em inglês quando o inglês está escolhido.
- **O instalador em português ou inglês** (#549): uma instalação nova pergunta antes o idioma, com o português escolhido, e as páginas dela e as do desinstalador o seguem. O app então abre nesse idioma na primeira vez. Atualizar a partir da 0.9.1 não pergunta nada e continua em português.
