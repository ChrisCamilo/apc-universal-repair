**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.7.1.exe`, or the portable exe to run without installing.

**Android:** the installed app says when this version is out and opens its APK, `apc-universal-repair-0.7.1.apk`. To install from scratch, open that file on the phone.

### Changes
- **Nothing changes on screen** (#425 to #428): the apps and the API work and look as in 0.7.0. The code behind them was reorganized, so each part of the app is found in the same place on the computer, the phone and the server, which makes the next features quicker to build.
