**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.6.6.exe`, or the portable exe to run without installing.

### What's new
- **About this version** (#305): *Sobre esta versão*, in the user menu, just before *Sair*, shows the version in use and these notes, in Portuguese.
  - *Ver todas as versões no GitHub* opens every release's notes in the browser.
  - The notes come with the app, so they show without internet.
- **Updating with its window:** this is the first update run by 0.6.5, so *Reiniciar agora* now shows the installer's window, *Atualizando o APC*, and opens the new version by itself (#298).
