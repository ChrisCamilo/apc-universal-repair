**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.6.5.exe`, or the portable exe to run without installing.

### What's new
- **The update's progress on screen** (#298): *Reiniciar agora* now opens the installer's window, titled *Atualização do APC Universal Repair*.
  - It shows *Atualizando o APC* with its progress bar, asks nothing, and opens the new version by itself when done.
  - A version installed on closing the app still goes in silently.
  - The update into 0.6.5 is run by the version before it, so it is still silent: the window shows from the next update on.
- **Uninstalling asks about the data** (#299): the uninstaller's new *Dados do APC* page shows the data's folder, its size and *Abrir a pasta*.
  - **Manter os dados neste computador**, the default, removes only the program. Installing again opens everything as it was.
  - **Apagar todos os dados do APC** also removes that folder: the inventory, the users, the photos and the backups, with no undoing it. It asks again first, with *Não* as the default.
  - An update never shows the page and always keeps the data. The [home server guide](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#13-uninstalling-the-app) explains each choice.
  - The uninstaller comes with the version installed, so the page shows from 0.6.5 on.

**Windows:** os apps instalados se atualizam sozinhos para esta versão. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.6.5.exe`, ou o exe portátil para rodar sem instalar.

### Novidades
- **O andamento da atualização na tela** (#298): o *Reiniciar agora* agora abre a janela do instalador, com o título *Atualização do APC Universal Repair*.
  - Ela mostra *Atualizando o APC* com a barra de progresso, não pergunta nada e abre a versão nova sozinha no fim.
  - Uma versão instalada ao fechar o app continua entrando em silêncio.
  - A atualização para a 0.6.5 é feita pela versão anterior, então ainda é silenciosa: a janela aparece a partir da próxima atualização.
- **Desinstalar pergunta sobre os dados** (#299): a nova página *Dados do APC* do desinstalador mostra a pasta dos dados, o tamanho dela e o *Abrir a pasta*.
  - **Manter os dados neste computador**, o padrão, remove só o programa. Instalar de novo abre tudo como estava.
  - **Apagar todos os dados do APC** remove também essa pasta: o estoque, os usuários, as fotos e as cópias de segurança, sem como desfazer. Ele pergunta de novo antes, com o *Não* como padrão.
  - Uma atualização nunca mostra a página e sempre mantém os dados. O [guia do servidor em casa](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#13-desinstalar-o-app) explica cada escolha.
  - O desinstalador vem com a versão instalada, então a página aparece a partir da 0.6.5.
