**Windows:** installed apps update themselves to this version. On its first start, a SQLite database is encrypted by itself, and the app shows its recovery key: keep it away from the computer. To install from scratch, download `APC-Universal-Repair-Setup-0.4.2.exe`, or the portable exe to run without installing.

### What's new
- **The SQLite database is encrypted:** the file in `%APPDATA%\APC Universal Repair\data` can't be read without its key, so a copy of it on a USB drive or a stolen disk shows nothing.
  - The key is made once and kept by Windows for your Windows user. Nothing to type day to day.
  - A database from before is encrypted on the first start after the update, through a copy removed once the encrypted file opens.
- **The recovery key:** the first time, the app shows the key's recovery copy, 8 groups of letters and numbers. Write it down or keep it in a password manager, away from the computer, and choose *Já guardei a chave*. Until then it shows on each opening.
  - Without it, a copy of the file opens on no other computer, nor after Windows is reinstalled.
  - A backup is restored on another computer by importing its `apc.db` with its recovery key, in *Servidor e banco de dados*, *Importar dados de outro servidor*.
- **A copy before each update's migrations:** when an update changes the database's structure, the server first copies the SQLite file to `data\backups`, keeping the last 3. A copy that can't be made stops the update of the database, saying why in `logs\api.log`. The [home server guide](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#6-backup) says how to go back to one.

**Windows:** os apps instalados se atualizam sozinhos para esta versão. Na primeira vez que abre, um banco SQLite é criptografado sozinho, e o app mostra a chave de recuperação dele: guarde-a longe do computador. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.4.2.exe`, ou o exe portátil para rodar sem instalar.

### Novidades
- **O banco SQLite é criptografado:** o arquivo em `%APPDATA%\APC Universal Repair\data` não pode ser lido sem a chave dele, então uma cópia num pendrive ou num disco roubado não mostra nada.
  - A chave é criada uma vez e guardada pelo Windows para o seu usuário do Windows. Nada para digitar no dia a dia.
  - Um banco de antes é criptografado na primeira vez que o app abre depois da atualização, por uma cópia apagada quando o arquivo criptografado abre.
- **A chave de recuperação:** na primeira vez, o app mostra a cópia de recuperação da chave, 8 grupos de letras e números. Anote ou guarde num gerenciador de senhas, longe do computador, e clique em *Já guardei a chave*. Até lá, ela aparece toda vez que o app abre.
  - Sem ela, uma cópia do arquivo não abre em nenhum outro computador, nem depois de reinstalar o Windows.
  - Um backup é restaurado em outro computador importando o `apc.db` dele com a chave de recuperação dele, no *Servidor e banco de dados*, *Importar dados de outro servidor*.
- **Uma cópia antes das migrações de cada atualização:** quando uma atualização muda a estrutura do banco, o servidor antes copia o arquivo SQLite para `data\backups`, mantendo as 3 últimas. Uma cópia que não pode ser feita para a atualização do banco, dizendo por quê no `logs\api.log`. O [guia do servidor em casa](https://github.com/ChrisCamilo/apc-universal-repair/blob/main/docs/home-server.md#6-backup-1) explica como voltar a uma delas.
