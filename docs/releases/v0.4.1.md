**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.4.1.exe`, or the portable exe to run without installing.

### What's new
- **The server's settings from the login:** the login screen has *Servidor e banco de dados*, next to *Esqueceu a senha?* and *Criar conta*. It opens the server's settings with no account, so an old server can be imported into a fresh install before anyone signs up: once someone does, the database isn't empty and the import refuses.

---

**Windows:** os apps instalados se atualizam sozinhos para esta versão. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.4.1.exe`, ou o exe portátil para rodar sem instalar.

### Novidades
- **As configurações do servidor pelo login:** a tela de login tem o *Servidor e banco de dados*, ao lado do *Esqueceu a senha?* e do *Criar conta*. Ele abre as configurações do servidor sem conta, para importar um servidor antigo numa instalação nova antes de alguém criar uma conta: depois disso o banco não está mais vazio e a importação recusa.
