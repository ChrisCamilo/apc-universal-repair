**Windows:** installed apps update themselves to this version. To install from scratch, download `APC-Universal-Repair-Setup-0.9.1.exe`, or the portable exe to run without installing.

**Android:** the installed app says when this version is out and opens its APK, `apc-universal-repair-0.9.1.apk`. To install from scratch, open that file on the phone.

### Changes
- **Nothing changes on screen** (#528 to #531, #536 to #538): the apps and the API work and look as in 0.9.0. The code behind them was reorganized: the Inventory of the computer and of the phone splits into folders by what each part does, the server keeps the rules of the catalog and of the item lists apart from its routes, and every refusal of the server is answered from one place. This makes the next features quicker to build.

**Windows:** os apps instalados se atualizam sozinhos para esta versão. Para instalar do zero, baixe o `APC-Universal-Repair-Setup-0.9.1.exe`, ou o exe portátil para rodar sem instalar.

**Android:** o app instalado avisa quando esta versão sai e abre o APK dela, o `apc-universal-repair-0.9.1.apk`. Para instalar do zero, abra esse arquivo no celular.

### Mudanças
- **Nada muda na tela** (#528 a #531, #536 a #538): os apps e a API funcionam e aparecem como na 0.9.0. O código por trás deles foi reorganizado: o Estoque do computador e o do celular se dividem em pastas pelo que cada parte faz, o servidor guarda as regras do catálogo e das listas de itens separadas das rotas, e toda recusa do servidor é respondida de um lugar só. Isso deixa as próximas funcionalidades mais rápidas de fazer.
